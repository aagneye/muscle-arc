# Beat public 0.4427: fold ensemble + rater-convention geometry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Lower the public UMUD score from 0.44273 (rank 120/433) toward 0.35 (rank ~50) with a reproducible, leaderboard-independent pipeline.

**Architecture:** Keep segmentation-then-geometry. (1) Cache per-image probability maps so geometry variants are evaluated in seconds on CPU. (2) Choose geometry and calibration on the 35-image six-rater OSF benchmark (host-recommended calibration set), never on public LB residuals. (3) When the GPUs free up, train 5-fold dual U-Nets on the deduplicated sequence-safe splits and average their probabilities.

**Tech Stack:** PyTorch + segmentation_models_pytorch (efficientnet-b4 U-Net, 512 px), OpenCV/NumPy geometry, Azure VM `rogii-gpu` (4x T4; GPUs held by another project until ~11:45 UTC 2026-10-18).

**Spec:** `docs/literature_review.md` sections 3 (host protocol) and 8 (design decisions); host rulings in memory `umud-competition-state-2026-10`.

## Global Constraints

- Metric: S = (MAE_PA/6 + MAE_FL/12 + MAE_MT/3) / 3.
- Final pipeline must re-run on a new dataset with no leaderboard (host rule): no per-image LB-tuned values, no pinned sample-submission rows.
- Output clip ranges = host's stated test ranges: PA 5–45°, FL 30–200 mm, MT 10–50 mm.
- Exact scale/crop come from `experiments/depth_scale_table_exact.csv`.
- Atomic commits, `<type>(<file>): <description>`.
- Never stop or touch the other project's processes on the VM; use only GPUs it is not using.

## Review Focus

1. Images where no fascicle survives the band filter → expect a prior (clip-median of the image's 5-frame run, else muscle-wide median), never NaN or 0.
2. Images with three aponeurosis bands (TA central apo, skin line) → expect the superficial compartment; covered by the existing apo-pair scoring, asserted in Task 2 on a synthetic three-band mask.
3. Fold models disagreeing strongly on one image → averaged probabilities must still threshold to a usable mask; Task 4 logs per-image fold disagreement.
4. 512x465 exports (no ruler, fixed 0.1285 mm/px) → scale comes from the exact table, never the 0.06 default; asserted in Task 1.
5. Calibration that helps OSF but hurts test distribution → gate every calibration with leave-one-out on OSF and a test-set distribution check (FL std not collapsed).
